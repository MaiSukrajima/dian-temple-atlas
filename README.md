# “庙”堂在野 · 文化润滇

文庙实践教学智能评价与数字档案系统，围绕滇中、滇南六庙调研与五维教学评价构建的单文件展示原型。

[打开在线演示](https://maisukrajima.github.io/dian-temple-atlas/)

![扫码访问在线演示](qr-code.png)

## 使用

在线打开 GitHub Pages 页面，或下载 index.html 后以新版 Edge / Chrome 本地打开。单文件已内嵌依赖和降级图，无需安装或联网加载第三方库。

- 四阶 Toon Shading、墨线古建、卡通泮池水面与昼夜切换。
- 阻尼轨道控制、23 秒礼制漫游与四处建筑微课。
- 六庙档案入口、区域筛选与分层保护对比。
- 四阶段课程进度与五维雷达、前后测柱状图、空间热力图联动。

## 资料和模型范围

建筑为综合形制示意，地图表达区域相对位置。史料与普查数据采用项目需求提供的摘要，原始测绘与档案页码尚待补录。呈贡、通海、嵩明的详细形制明确标注待核录。

教学评价使用预设模拟分值，页面已展示仿真注释和计算规则。当前版本包含前端展示及本地计算。

## 技术

Three.js 0.160.1 ES Modules、OrbitControls、Tailwind CSS 2.2.19 工具类子集、Lucide 0.468.0 图标子集及原生 Canvas。WebGL 不可用时显示内嵌静态图景，档案、微课和评价仍可访问。
